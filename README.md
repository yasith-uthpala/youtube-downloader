# 🚀 YouTube Pro Downloader (All Qualities, 60 FPS & Auth Support)

A modern, fast, and full-featured YouTube Video & Audio Downloader with a simple and clean UI.

---

## ✨ Features

- **All Resolutions Supported:**
  - 8K Ultra HD (4320p)
  - 4K Ultra HD (2160p)
  - 2K Quad HD (1440p)
  - 1080p Full HD
  - 720p HD
  - 480p, 360p, 240p, 144p
- **High Framerate (FPS) Detection:**
  - Automatically detects and highlights **60 FPS** and **50 FPS** streams with special badges.
  - Standard 30 FPS / 24 FPS streams also available.
- **Full Video + Audio Merging:**
  - Uses embedded **FFmpeg** to merge separate YouTube DASH video and pristine audio streams into high-quality **MP4** files.
- **Audio Extraction:**
  - 1-Click extraction to **320kbps MP3** (universally compatible) or original **M4A (AAC)** audio.
- **YouTube Login & Anti-Bot Bypass:**
  - **Browser Session Integration:** Auto-detects and extracts cookies from your local browser (**Opera GX**, Microsoft Edge, Google Chrome, Firefox, Brave) so you can download age-restricted, private, or anti-bot checked videos without logging in again!
  - **Custom cookies.txt Upload:** Drag-and-drop or upload exported cookies file.
- **Real-Time Live Progress:**
  - Shows download speed (MB/s), percentage (0-100%), remaining ETA, and audio/video merging status.
  - Automatically triggers the browser file download once complete.
- **One-Click "Open Downloads Folder":**
  - Quickly opens your local downloads folder in Windows File Explorer.

Simply double-click the **`run.bat`** file in this folder. It will start the server and open your browser automatically at `http://localhost:8000`.
